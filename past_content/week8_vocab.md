# Week 8: Key Vocabulary

## 1. MVP (Minimum Viable Product)
The smallest version of an application that proves its main value to users.

**Example:** A simple chatbot that answers questions, remembers conversations, and handles basic errors without needing a fancy interface.

## 2. Test Case
An input, the expected behavior, and the actual observed result.

**Example:**
- Input: Press Enter without typing anything.
- Expected behavior: The chatbot asks the user to type something.
- Observed result: The chatbot prints "Please type something."

## 3. Limitation
A boundary of what an application can do or how reliably it can perform a task.

**Example:** A study coach chatbot may not have access to live information or may occasionally give incorrect explanations.

## 4. Demo (Demonstration)
A short, evidence-based presentation that shows how an application actually works.

**Example:** Running your chatbot, asking it a question, showing how it responds, and demonstrating how it handles unexpected inputs.
